# Personal Creator Roadmap

Цель — сократить Critical Chain производства видео, а не накопить максимальное количество функций.

## Focus chain

`замысел → подготовка → запись хорошего take → быстрый монтаж → нужные варианты → хранение/публикация`

Текущее ограничение: после записи и экспорта остаётся много ручных операций и переключений между
инструментами.

## Приоритеты

| Приоритет | Ставка | Job / ценность | Самый дешёвый RAT |
|---|---|---|---|
| P0 | Надёжный Яндекс Диск backup | Не потерять take и открыть его с другого устройства | 10 реальных записей с raw-upload |
| P0 | Безопасное обновление upstream | Получать bugfix/native improvements без потери кастомных функций | Один полный sync + merge на `creator-edition` |
| P1 | Recording recipes | Одним действием восстановить source, mic, camera, cursor, countdown и export preset | 3 сохранённых preset в local JSON |
| P1 | Timestamp markers + notes | Во время записи пометить дубль, ошибку, главу или CTA и увидеть marker на timeline | Hotkey + простой marker sidecar |
| P1 | Take manager | Быстро сравнивать, переименовывать, удалять и возвращаться к дублям | Список последних 10 sessions без media database |
| P1 | Export recipes | Одним export получить YouTube 16:9, Shorts 9:16 и GIF preview | Два preset без batch-render |
| P1 | Upload final export | Сразу получить готовый MP4 на Диске после render | Отдельный checkbox в Export panel |
| P2 | Script / teleprompter overlay | Не переключаться между сценарием и записываемым приложением | Markdown script + scroll-speed control |
| P2 | Local transcript cleanup | Быстро убрать паузы, повторы и слова-паразиты | Предпросмотр предложенных cuts, без auto-apply |
| P2 | Project bundle backup | Восстановить не только raw, но и editable project | Zip одного проекта + manifest validation |

## Сильнейший следующий ход после pilot

Если raw-файлы реально открываются с Диска — добавить persistent retry queue. Если в облаке нужны
только готовые ролики — остановить raw-upload по умолчанию и перенести интеграцию в export flow.

Не делать одновременно оба направления до данных первых 10 записей.

## Feature gate для каждой новой функции

Перед разработкой ответить:

1. Какой участок Critical Chain она сокращает?
2. Какая no-build альтернатива уже существует?
3. Какой один измеримый outcome должен измениться?
4. Какое предположение самое рискованное?
5. Как проверить его за 1–2 дня без полной реализации?
6. Что явно не входит в MVP?
7. Где функция изолируется, чтобы не повышать стоимость upstream sync?

## Stop rules

- feature не используется в 5 последовательных релевантных сессиях;
- экономия времени меньше 30 секунд, но функция добавляет постоянный UI/maintenance cost;
- функция требует менять native recorder без прямой ценности для capture quality;
- одно и то же поведение уже надёжно даёт внешний инструмент или системный shortcut;
- интеграция расширяет OAuth-права без подтверждённого Job.
