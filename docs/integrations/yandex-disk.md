# Яндекс Диск: настройка и проверка

## Настройка

1. Создать OAuth-приложение в [Яндекс OAuth](https://oauth.yandex.ru/client/new).
2. Выдать только доступ к папке приложения: `cloud_api:disk.app_folder`.
3. Получить debug OAuth-токен для личного pilot.
4. В OpenScreen нажать иконку облака в HUD.
5. Вставить токен, выбрать подпапку и включить автозагрузку.

Токен проверяется обращением к папке приложения и хранится зашифрованно через Electron
`safeStorage`. Renderer не может прочитать сохранённое значение.

## Что загружается

После остановки отправляется только основной raw-файл `screenVideoPath`:

```text
app:/Recordings/recording-<timestamp>.webm
```

или `.mp4` для native pipeline. Webcam sidecar, cursor telemetry, project и export в текущий MVP не
входят.

## Ручной smoke test

1. Оставить интеграцию выключенной: остановить запись, убедиться, что сетевого upload нет.
2. Подключить валидный токен и включить upload.
3. Записать 5–10 секунд, остановить.
4. Убедиться, что editor открылся до завершения upload.
5. Проверить файл в папке приложения на Диске.
6. Отключить сеть, повторить запись, проверить локальный editor и error notification.
7. Вставить неверный токен: настройка должна вернуть ошибку и не сохранить соединение.
8. Нажать Disconnect и проверить, что следующий take не отправляется.

## Известные ограничения

- очередь не переживает закрытие приложения;
- нет progress в процентах;
- нет автоматического refresh token;
- лимиты размера и квоты определяются аккаунтом Яндекс Диска;
- полный OAuth + PKCE нужен до распространения сборки другим пользователям.
