# Яндекс Диск: настройка и проверка

Целевая папка: [OpenScreen Exports](https://disk.yandex.ru/d/GKhvA2QkXOBe2g).

## Настройка OAuth

1. Открыть существующее приложение в [Яндекс OAuth](https://oauth.yandex.ru/).
2. Добавить доступы `cloud_api:disk.read` и `cloud_api:disk.write`.
3. Получить новый токен по кнопке в OpenScreen. Старый токен с `app_folder` не получит новые права
   автоматически.
4. В OpenScreen нажать иконку облака в HUD.
5. Вставить токен и оставить путь `OpenScreen Exports`.
6. Включить автозагрузку. Параметр удаления локального файла включён по умолчанию.

Client Secret для личного debug token не используется и не должен попадать в приложение, GitHub или
документацию. Токен проверяется обращением к целевой папке и хранится зашифрованно через Electron
`safeStorage`; renderer не может прочитать сохранённое значение.

## Что загружается

После остановки отправляется основной raw-файл `screenVideoPath`:

```text
disk:/OpenScreen Exports/recording-<timestamp>.webm
```

или `.mp4` для native pipeline. Webcam sidecar, cursor telemetry, project и export не входят в
текущий срез.

Перед upload приложение проверяет, что `disk:/OpenScreen Exports` соответствует публичной ссылке
`GKhvA2QkXOBe2g`. После upload оно повторно читает метаданные и сравнивает тип и размер удалённого
файла с локальным.

## Локальное удаление

- при ошибке upload или проверки локальная запись всегда сохраняется;
- во время работы редактора файл не удаляется;
- после подтверждённой загрузки создаётся отложенная задача удаления;
- задача выполняется при возврате из редактора в HUD или при следующем запуске приложения;
- если Windows не позволяет удалить файл, приложение показывает ошибку и повторяет попытку позже;
- параметр можно отключить в панели Яндекс Диска.

## Ручной smoke test

1. Подключить новый токен и убедиться, что OpenScreen принял путь `OpenScreen Exports`.
2. Записать 5–10 секунд и остановить запись.
3. Убедиться, что editor открылся до завершения upload.
4. Дождаться success-toast и проверить файл по публичной ссылке.
5. Пока editor открыт, убедиться, что preview продолжает работать.
6. Вернуться в HUD и проверить уведомление об удалении локальной копии.
7. Повторить с отключённым интернетом: локальный файл должен остаться.
8. Отключить локальное удаление, записать ещё один take и убедиться, что файл сохранён и локально,
   и на Диске.

## Известные ограничения

- очередь upload не переживает закрытие приложения;
- очередь уже подтверждённых локальных удалений переживает перезапуск;
- нет progress в процентах;
- нет автоматического refresh token;
- полный OAuth + PKCE нужен до распространения сборки другим пользователям.
