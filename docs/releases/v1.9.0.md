**OpenScreen Creator Edition** is a free, open-source screen recorder and editor: record part of the screen, get an MP4 in your folder the moment you stop, send it, or polish it in Studio. No accounts, no paid tiers.

**Коротко по-русски.** Бесплатная программа для записи экрана с открытым кодом. Выделяете область, записываете — MP4 сразу в папке, ссылку можно скопировать через Яндекс Диск. Новое: расшифровка записи в текст и субтитры прямо на компьютере, реалистичные мокапы устройств в Студии. Скачайте файл для своей системы ниже.

## Download

| System | File |
|---|---|
| Windows 10 / 11 | `OpenScreen-Custom-1.9.0-Setup.exe` |
| macOS, Apple Silicon (M1 and later) | `OpenScreen-Mac-arm64-1.9.0.dmg` |
| macOS, Intel | `OpenScreen-Mac-x64-1.9.0.dmg` |
| Linux | `.AppImage` (any distro), `.deb` (Debian, Ubuntu), `.pacman` (Arch) |

The installers are not code-signed, so the first launch needs one extra step:

- **Windows:** if SmartScreen says "Windows protected your PC", click **More info → Run anyway**.
- **macOS:** drag OpenScreen to Applications, then run `xattr -rd com.apple.quarantine /Applications/OpenScreen.app` in Terminal and grant Screen Recording when asked.
- **Linux:** `chmod +x OpenScreen-Linux-*.AppImage` and run it, or install the `.deb` / `.pacman`.

## What's new

- **Transcription.** Press **Transcribe** on a finished clip and get `<clip>.txt` (paragraphs with timestamps) and `<clip>.srt` subtitles next to the video. It runs on your computer and uploads nothing: Whisper large-v3-turbo on the graphics card, Whisper small on the processor elsewhere, language detected automatically. The speech model downloads once, the first time you transcribe (about 560 MB for the graphics-card model, 250 MB for the processor one). Studio's auto captions use the same engine.
- **Transcription is optional on Windows.** The installer asks whether to install it; clear the box to leave it out (or install silently with `/S /NOTRANSCRIPTION`).
- **Realistic device mockups** in Studio: phones, tablet, laptop and a browser window, drawn with real materials and shadows at any export size.
- **Long recordings are kept as recorded.** A take of five minutes or more is never re-encoded, and Restart / Delete ask twice once a take is longer than a few seconds.
- **Smaller download:** the Windows installer went from 290 MB to about 157 MB.

## Also in Creator Edition

- Quick clips: pick an area (or a window, or the screen), record with one hotkey, and the MP4 is in your folder a second after you stop.
- Copy a shareable link through Yandex Disk, copy the file, or drag the clip straight into a chat.
- Studio: frame the video with backgrounds and devices, set the aspect ratio, crop to exact pixels, split the clip and cut parts out, export MP4 or GIF from one button.
